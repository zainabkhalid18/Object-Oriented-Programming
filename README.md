# Hospital Management System
A console-based Hospital Management System built in C++ using Object-Oriented Programming (OOP) concepts. It allows users to book patient appointments, view the doctor list, select a preferred doctor, and process payments, all through a simple text menu.

## Features
1. Emergency Appointment Booking — Quickly book an appointment by entering patient details
2. Doctor List with Specializations — View all available doctors and their fields
3. Doctor-Specific Appointments — Select a doctor and book directly with them
4. Payment Processing — Enter payment details and receive a printed summary receipt
5. Loop Menu — Continue using the system without restarting


## Technologies Used
### Language: C++
### Concepts: Classes, Inheritance, Member Functions, Switch-Case, Loops
### Libraries: iostream, conio.h


## How to Run
### Requirements: A C++ compiler (e.g., Dev-C++, Code::Blocks, or g++)
### Steps:
1. Clone or download the project
2. Open main.cpp in your IDE or compile via terminal
